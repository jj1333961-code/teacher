🔗 مزامنة المشروع مع GitHub

المشروع مرتبط بمستودعك الشخصي فقط عبر متغيرات البيئة على الخادم (GITHUB_TOKEN, GITHUB_OWNER, GITHUB_REPO, GITHUB_BRANCH). كل إضافة أو تعديل يقوم به مساعد التطوير يُنشئ Commit ويُدفع تلقائياً إلى فرعك المحدد، مع الحفاظ على كامل تاريخ الإصدارات. لا يتم وضع أي مفتاح أو سرّ داخل الملفات أو في المتصفح.
